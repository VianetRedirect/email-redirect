# Power-ups: first 30

Three families. Slots: 3 ball, 2 flipper, 4 passive.
Tags: Shock, Burn, Hack, Magnet, Split.
Rarity: C common, U uncommon, R rare.

## Ball mods: what the ball is

| # | Name | Tags | Rarity | Effect |
|---|------|------|--------|--------|
| B1 | Arc Ball | Shock | C | Each hit chains 1 damage to the nearest enemy within 60 px |
| B2 | Thermite Core | Burn | C | Leaves a 2 second burning trail. Enemies in it take 1 damage per second |
| B3 | Splitter | Split | U | The third bumper hit in a row splits off a clone ball for 6 seconds |
| B4 | Ghost Packet | Hack | U | Passes through the first wall it touches after each flip |
| B5 | Lodestone | Magnet | C | Curves gently toward the nearest unlit node |
| B6 | Heavy Slug | none | C | Double damage, 15% slower, drones no longer deflect it |
| B7 | Static Charge | Shock | U | Builds charge while rolling. The next hit releases it as area damage |
| B8 | Napalm Shell | Burn, Split | R | On killing an enemy, bursts into 3 short-lived fire shards |
| B9 | Worm | Hack | R | A hit on a node also lights the nearest other node at half progress |
| B10 | Rail Round | Magnet | R | After 1 second above 80% speed, pierces enemies instead of bouncing |

## Fusions

Two ball mods that share a tag can fuse at the upgrade screen. The result
takes one slot.

| Fusion | From | Effect |
|--------|------|--------|
| Storm Cell | Arc Ball + Static Charge | Chains to 3 enemies. Charge builds twice as fast |
| Firestorm | Thermite Core + Napalm Shell | Trail lasts 4 seconds. Shards leave trails too |
| Rootkit | Ghost Packet + Worm | Passing through a wall lights the nearest node at half progress |
| Maglev | Lodestone + Rail Round | Piercing shots curve toward the next enemy |

## Example builds

- **Storm.** Tesla Tips, Arc Ball, Static Charge, Capacitor Bank. Every flip
  starts a chain and every kill explodes.
- **Swarm.** Splitter, Fork, Twin Link, Mirror Shard. Flood the table with
  balls and let volume do the work.
- **Ghost.** Ghost Packet, Worm, Backdoor, Daemon. Skip the table and open
  gates fast. Low damage, high speed.
- **Control.** Mag Grip, Coil Launcher, Lodestone, Insurance. Catch, aim,
  fire. For players who want precision.

## Balance rules for later

- Test pairs and triples, not single items.
- Every tag needs at least one item in each family so any build can start
  from any first pick.
- No item should make flipping unnecessary.
