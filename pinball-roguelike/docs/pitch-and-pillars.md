## Three pillars

Every feature must serve at least one. If it serves none, it waits.

1. **Every shot is a choice.** _What this means for the table and the pick-ups._
2. **A run is ten minutes.** _What this means for floor count and ball count._
3. **The base changes the next run.** _What this means for what carries home._
